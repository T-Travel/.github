# ✈️ T-Travel

### Сервис совместных путешествий

> Планируй поездки вместе.  
> Управляй общим бюджетом.  
> Разделяй расходы без ручных подсчётов.

---

## 🌍 О проекте

**Т-Путешествие** — сервис для совместного планирования поездок,
управления общим бюджетом и прозрачного распределения расходов
между участниками путешествия.

Сервис позволяет группе путешественников создавать поездки,
приглашать участников, вести расходы, контролировать бюджет
и автоматически рассчитывать взаиморасчёты.

Проект разрабатывается в рамках образовательного проекта
**Т-Образование** и ориентирован на экосистему **Т-Банка**.

---

## 🚀 Возможности

### 🧳 Планирование поездки

- создание поездки;
- название, даты и валюта поездки;
- приглашение участников по e-mail или телефону;
- подтверждение участия;
- роли владельца поездки и участника.

### 💰 Общий бюджет

- категории расходов;
- стандартные и пользовательские категории;
- общий лимит бюджета;
- контроль текущих расходов.

### 🧾 Расходы

- добавление расходов участниками;
- указание плательщика;
- выбор участников, за которых произведён расход;
- распределение суммы поровну или по заданным долям;
- категория расхода;
- валюта;
- фотография чека.

### 📊 Взаиморасчёты

Сервис автоматически рассчитывает:

- сколько потратил каждый участник;
- сколько каждый должен получить;
- сколько каждый должен вернуть;
- кто кому должен;
- оптимальные взаиморасчёты с минимальным количеством переводов.

### 🔔 Уведомления

Участники получают уведомления об изменениях:

- новые расходы;
- изменения бюджета;
- изменения поездки;
- закрытие поездки.

### 📜 История

Для каждой поездки формируется история событий,
позволяющая отслеживать изменения и действия участников.

### 📤 Экспорт

Итоговые данные поездки можно экспортировать в формате **CSV**.

## 🔐 Безопасность

В проекте предусматриваются:

- аутентификация пользователей;
- JWT / session-based authentication;
- авторизация с учётом конкретной поездки;
- разграничение ролей владельца и участника;
- ограничения частоты отправки приглашений;
- транзакционная работа с данными;
- версионирование для согласованного пересчёта балансов.
